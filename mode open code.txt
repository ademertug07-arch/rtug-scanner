Ultrawork modu tamamen kuruldu. Değişiklikler:

1. opencode.jsonc — 3 yeni subagent eklendi
generator — kod yazar, production-quality, websearch erişimli
critic — denetler, edit yetkisi YOK (read-only), PASS/FAIL verir
fixer — critic'in bulduğu her sorunu çözer
2. .ultrawork/ dizini oluşturuldu
config.json — max 10 iterasyon, kalite gate'leri, rol tanımları
state.json — canlı state tracker (iteration, status, currentPhase)
template-task.md — her loop için standart workflow şablonu
.gitkeep — dizin takibi için
3. Komutlar güncellendi
/apply-ultrawork-mode — detaylı setup adımları (dizin, config, state, doğrulama)
/ulw-loop — 4 adımlı adversarial loop template (Analyze→Generate→Critique→Resolve), iteration tracking, failsafe
/ulw-status — yeni, anlık state ve geçmiş gösterimi
/cancel-loop — loop durdurma
4. AGENTS.md güncellendi
Ultrawork kullanım talimatı eklendi: /apply-ultrawork-mode → /ulw-loop → /ulw-status → /cancel-loop

Kullanım: /apply-ultrawork-mode yaz, ardından /ulw-loop ile loop'u başlat.
