# Vibe Team — Takım Rolleri

| Rol | Sorumluluk |
|-----|-----------|
| **Product Lead** | Requirements + acceptance criteria. Scope'u real user outcomes'a bağlı tutar. Final behavior'a imza atar. |
| **Builder** | Model'i yönlendirir + değişiklikleri entegre eder. Vibe loop'u çalıştırır, diff'leri küçük tutar. Decision'ları ve open issue'ları belgeler. |
| **Reviewer** | Diff'leri okur, outcome'ları test eder, risk'leri tespit eder. Performans ve security impact'ini doğrular. Açık feedback ile onaylar/reddeder. |

Standartlar: Tutarlı prompt formatı + tutarlı review checklist.
Reviewer'ları döndürerek kör noktaları azalt.
