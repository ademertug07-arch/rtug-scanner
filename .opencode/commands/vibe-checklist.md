# Vibe Coding Checklist — Release Freni

Her iterasyonun sonunda bu checklist'i uygula:

- [ ] Goal, constraints, acceptance yazıldı mı?
- [ ] Prompt scope küçük ve file boundaries net mi?
- [ ] Generated code review edildi mi? (logic + dependencies)
- [ ] App local'de çalışıyor ve critical flow'lar geçiyor mu?
- [ ] Testler ilgili alanlarda koşuldu mu?
- [ ] Gerekli dokümantasyon/notlar güncellendi mi?
- [ ] Commit net bir mesajla oluşturuldu mu?
- [ ] Follow-up task'ler kaydedildi/kapatıldı mı?

> "En küçük değişiklik bile checklist'ten geçmeli. Çoğu regresyon 'küçük' edit'lerden gelir."
