# Vibe Hygiene — Workflow Disiplini

| Alışkanlık | ROI |
|------------|-----|
| Commit like checkpoints | ★★★★★ |
| Keep a prompt log | ★★★★★ |
| Track TODOs explicitly | ★★★★ |
| Reset context when it drifts | ★★★★ |
| Keep diffs small | ★★★★ |
| Document decisions | ★★★ |

## Prompt Log Format
```
# prompt-log.md
## 2026-07-07
- [x] Feature X: <prompt özeti> → <outcome>
- [ ] Bug Y: <prompt özeti> → <beklemede>
```

## Handoff Format
```
Context: <short summary of goal>
Changes: <files touched + why>
Checks: <tests or commands run>
Open Issues: <what is left>
Next Prompt: <recommended next instruction>
```
